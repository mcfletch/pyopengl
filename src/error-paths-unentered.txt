# Error paths in OpenGL/ that a run of the suite does not enter.
# An `except` clause or a `finally` block nothing reaches is one
# nothing has ever checked, and that is where this package keeps
# finding handlers that raise instead of reporting.
#
# Written by:
#     coverage run -m pytest tests/ && coverage combine
#     python src/check_error_paths.py --write
# Read by the same script without --write, which fails on a
# handler that is unentered and NOT here.  A handler here that
# has started running is reported and does not fail: this list
# is written from the `errorpaths` tox environment -- numpy
# present, PyOpenGL_accelerate built, the EGL device backend on
# Linux -- and another configuration enters a different set.
# Re-record from that environment, or the difference between
# two configurations reads as a regression.
#
# The list is meant to shrink.  Each line is a case somebody
# could write, or a path that has to be recorded because this
# machine cannot reach it; where the reason is known, say it
# after the `#` and --write will keep it.
#
# A handler is named by scope rather than by line, so adding a
# line above one does not rewrite the file:
#     <module path>::<scope>::<exceptions>::<ordinal>
